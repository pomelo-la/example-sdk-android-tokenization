# Android Tokenization Examples

Este repositorio agrupa ejemplos de integración para tokenización en Android.

## Ejemplos

- [example-android-pomelo-sdk](example-android-pomelo-sdk): app Android de ejemplo usando el SDK de Pomelo para Push Provisioning.
- [example-android-app-google-upp](example-android-app-google-upp): ejemplo de integración Google UPP con una app Android y un backend de referencia.
